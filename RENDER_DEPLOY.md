# 🚀 Quick Deployment Instructions for Render

## ✅ Your code is already pushed to GitHub!

Repository: https://github.com/Pavanahirwar9/ai-code-reviewer

## Next Steps to Deploy:

### 1. Go to Render Dashboard
Visit: https://dashboard.render.com

### 2. Deploy Using Blueprint

1. Click **"New +"** button
2. Select **"Blueprint"**
3. Connect to your GitHub repository: `Pavanahirwar9/ai-code-reviewer`
4. Render will detect the `render.yaml` file
5. Click **"Apply"**

### 3. Configure Environment Variables

Render will create 2 services:
- `ai-code-review-backend`
- `ai-code-review-frontend`

#### For Backend Service:

Click on the backend service, go to "Environment" tab, and add:

```
MONGODB_URI = (copy from your local .env file)
OPENAI_API_KEY = (copy from your local .env file)  
GITHUB_CLIENT_ID = (copy from your local .env file)
GITHUB_CLIENT_SECRET = (copy from your local .env file)
FRONTEND_URL = (will update after frontend deploys)
```

Note: JWT_SECRET and SESSION_SECRET will be auto-generated by Render.

#### For Frontend Service:

Click on the frontend service, go to "Environment" tab, and add:

```
NEXT_PUBLIC_API_URL = (use backend URL after it deploys)
```

Example: `https://ai-code-review-backend.onrender.com/api`

### 4. Update CORS After Both Deploy

1. After frontend deploys, copy its URL
2. Go to backend service → Environment
3. Update `FRONTEND_URL` to the frontend URL
4. Save (will auto-redeploy)

### 5. Test Your Deployment

- Frontend: Visit your frontend URL
- Backend Health: `https://your-backend.onrender.com/health`

## Important Notes

- ⏱️ First load takes 30-60 seconds (free tier services sleep after inactivity)
- 🔐 Keep your API keys secure - they're in your local .env files
- 📊 MongoDB Atlas must allow connections from `0.0.0.0/0` (all IPs)
- 🔄 Future updates: Just push to GitHub, Render will auto-deploy!

## Troubleshooting

If deployment fails:
1. Check Render service logs
2. Verify all environment variables are set
3. Check MongoDB connection (password encoding: @ = %40)
4. Ensure you're using the correct backend URL in frontend
