## Issues Fixed

**Problem:** GitHub callback URL was pointing to localhost
**Solution:** Added `GITHUB_CALLBACK_URL` environment variable to render.yaml

### 2. Download Report Not Working  
**Problem:** Frontend had hardcoded `http://localhost:5000` URL
**Solution:** Updated to use `NEXT_PUBLIC_API_URL` environment variable and added credentials

**Problem:** CORS not configured for production URLs and cookies not working across domains
**Solution:** Updated CORS to allow multiple origins and set `sameSite: 'none'` for production

## Environment Variables to Set in Render

### Backend Service (`ai-code-review-backend`)

You need to set these environment variables in your Render dashboard:

1. **MONGODB_URI** (required)
   - Your MongoDB connection string
   - Example: `mongodb+srv://username:password@cluster.mongodb.net/ai-code-review`

2. **OPENAI_API_KEY** (required)
   - Your OpenAI API key
   - Example: `sk-proj-...`

3. **GITHUB_CLIENT_ID** (required for GitHub OAuth)
   - Your GitHub OAuth App Client ID
   - Get from: https://github.com/settings/developers

4. **GITHUB_CLIENT_SECRET** (required for GitHub OAuth)
   - Your GitHub OAuth App Client Secret
   - Get from: https://github.com/settings/developers

5. **GITHUB_CALLBACK_URL** (required for GitHub OAuth) - **NEW!**
   - Format: `https://YOUR-BACKEND-URL.onrender.com/api/github/callback`
   - Example: `https://ai-code-reviewer-backend-wbf1.onrender.com/api/github/callback`
   - ⚠️ **IMPORTANT:** This must match the Authorization callback URL in your GitHub OAuth App settings!

6. **FRONTEND_URL** (required)
   - Your frontend URL
   - Example: `https://ai-code-reviewer-frontend.onrender.com`
   - Or your custom domain if you have one

7. **JWT_SECRET** (auto-generated by Render)
   - Leave as is (Render generates this automatically)

8. **SESSION_SECRET** (auto-generated by Render)
   - Leave as is (Render generates this automatically)

### Frontend Service (`ai-code-review-frontend`)

1. **NEXT_PUBLIC_API_URL** (required)
   - Your backend API URL
   - Format: `https://YOUR-BACKEND-URL.onrender.com/api`
   - Example: `https://ai-code-reviewer-backend-wbf1.onrender.com/api`

## GitHub OAuth App Configuration

1. Go to: https://github.com/settings/developers
2. Click on your OAuth App (or create a new one)
3. Set **Authorization callback URL** to:
   ```
   https://YOUR-BACKEND-URL.onrender.com/api/github/callback
   ```
   ⚠️ This MUST match your `GITHUB_CALLBACK_URL` environment variable!

4. Set **Homepage URL** to:
   ```
   https://YOUR-FRONTEND-URL.onrender.com
   ```

## Deployment Steps

### 1. Update Environment Variables in Render

For **Backend Service**:
1. Go to your backend service in Render dashboard
2. Click "Environment" in the left sidebar
3. Add/Update the following variables:
   - `GITHUB_CALLBACK_URL` = `https://YOUR-BACKEND-URL.onrender.com/api/github/callback`
   - `FRONTEND_URL` = `https://YOUR-FRONTEND-URL.onrender.com`
   - Make sure all other required variables are set

For **Frontend Service**:
1. Go to your frontend service in Render dashboard
2. Click "Environment" in the left sidebar  
3. Add/Update:
   - `NEXT_PUBLIC_API_URL` = `https://YOUR-BACKEND-URL.onrender.com/api`

### 2. Update GitHub OAuth App

1. Go to https://github.com/settings/developers
2. Update **Authorization callback URL** to match your `GITHUB_CALLBACK_URL`

### 3. Deploy the Changes

1. Commit and push the code changes:
   ```bash
   git add .
   git commit -m "Fix: Render deployment issues with GitHub OAuth and download"
   git push origin main
   ```

2. Render will automatically detect the changes and redeploy both services

### 4. Verify the Deployment

After deployment completes:

1. **Test GitHub Connection:**
   - Go to your frontend URL
   - Login/Register
   - Navigate to Dashboard → GitHub
   - Click "Connect GitHub"
   - Complete the OAuth flow
   - ✅ Should redirect back with success message

2. **Test Report Download:**
   - Create a code review
   - Go to the results page
   - Click "Download Report"
   - ✅ Should download a `.txt` file

## Common Issues & Solutions

### Issue: "Not allowed by CORS"
**Solution:** Make sure `FRONTEND_URL` environment variable is set correctly in your backend service

### Issue: GitHub OAuth redirects to localhost
**Solution:** Check that `GITHUB_CALLBACK_URL` is set in Render and matches your GitHub OAuth App settings

### Issue: Download doesn't start
**Solution:** 
- Check browser console for errors
- Verify `NEXT_PUBLIC_API_URL` is set in frontend
- Make sure you're logged in (check localStorage for token)

### Issue: "Failed to download report"
**Solution:**
- Check backend logs in Render
- Verify the review ID exists
- Make sure authentication token is valid

## Testing Locally

To test these changes locally:

1. Set environment variables:
   ```bash
   # Backend (.env)
   GITHUB_CALLBACK_URL=http://localhost:5000/api/github/callback
   FRONTEND_URL=http://localhost:3000
   
   # Frontend (.env.local)
   NEXT_PUBLIC_API_URL=http://localhost:5000/api
   ```

2. Start both services:
   ```bash
   # Backend
   cd backend
   npm start
   
   # Frontend (in new terminal)
   cd frontend
   npm run dev
   ```

3. Test GitHub OAuth and download functionality
